# NWC RAG Website

A bilingual Arabic/English retrieval-augmented assistant website. It retrieves answers from the JSON documents in `jsonchunks/`, uses a local Milvus Lite database, and supports Groq or a locally running Qwen model for text answers.

## Features

- Arabic and English question answering with source snippets.
- Browser-based voice input with transcription review before submitting.
- Local web interface and API served together on port `8000`.
- The generated vector index stays local; the API key is read from `.env`.

## Requirements

- Python 3.10 or later.
- A Groq API key for Groq-powered answers or optional voice transcription.
- Internet access on first run to download the embedding model and call Groq.

## Setup (Windows PowerShell)

From the repository root:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
```

Edit `.env` and choose the answer provider. For the default Groq answer model:

```text
RAG_LLM_PROVIDER=groq
GROQ_API_KEY=replace-with-your-groq-api-key
# Optional; defaults to whisper-large-v3
GROQ_TRANSCRIPTION_MODEL=whisper-large-v3
```

Build the local vector index from the included source documents, then start the server:

```powershell
.\.venv\Scripts\python.exe .\rag-website\create_embeddings.py
.\.venv\Scripts\python.exe .\rag-website\api.py
```

Open [http://127.0.0.1:8000/](http://127.0.0.1:8000/) in a browser. The first index build downloads the embedding model and may take some time. The generated Milvus database and embedding output are local files and are intentionally excluded from Git.

## Run answers locally with Qwen and Ollama

Ollama runs the answer-generation model on your computer. The Qwen embedding model and Milvus Lite index are also local. No Groq key is needed for text questions in this mode. Voice transcription still uses Groq and requires a key if you use the microphone feature.

1. Install Ollama for Windows from [ollama.com/download](https://ollama.com/download), then open PowerShell.
2. Download a Qwen model (the 8B model needs more memory; use `qwen3:4b` on a less powerful computer):

   ```powershell
   ollama pull qwen3:8b
   ```

3. In the repository root, edit `.env` and set:

   ```text
   RAG_LLM_PROVIDER=ollama
   OLLAMA_MODEL=qwen3:8b
   OLLAMA_BASE_URL=http://localhost:11434/v1
   ```

   If you downloaded the smaller model, use `OLLAMA_MODEL=qwen3:4b`. You can leave `GROQ_API_KEY` as the example placeholder when not using voice transcription.
4. Ensure Ollama is running, then build the index if you have not already and start the app:

   ```powershell
   .\.venv\Scripts\python.exe .\rag-website\create_embeddings.py
   .\.venv\Scripts\python.exe .\rag-website\api.py
   ```

5. Open [http://127.0.0.1:8000/](http://127.0.0.1:8000/). The first run downloads the embedding model; model downloads require internet. Later text answers are generated by Ollama on your machine.

To switch back to Groq, set `RAG_LLM_PROVIDER=groq` in `.env` and provide a valid `GROQ_API_KEY`.

## API

- `GET /health` checks server status.
- `POST /ask` accepts JSON such as `{"question":"..."}`.
- `POST /transcribe?language=ar` accepts an audio recording. Use `language=en` for English.
- `POST /clear` clears in-memory conversation history.

By default, the API listens only on `127.0.0.1`. Do not expose it directly to the public internet: it has no authentication or rate limiting. Add appropriate access controls before deploying it for public use.

## Privacy and data

The source JSON documents under `jsonchunks/` are included in this repository. In Groq mode, questions are sent to Groq; in Ollama mode, text answers are generated locally. Voice recordings are sent to Groq for transcription and are not saved by this application. Do not put personal, confidential, or otherwise restricted information in the documents or requests.

## Repository contents

- `rag-website/` — Python API, retrieval logic, and web application.
- `jsonchunks/` — source documents used to build the search index.
- `assets/` — website logo.

Generated files, virtual environments, local databases, conversation history, and API secrets should not be committed. See `.gitignore`.
